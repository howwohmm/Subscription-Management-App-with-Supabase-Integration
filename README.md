# Subscription-Management-App-with-Supabase-Integration

> Track and manage recurring subscriptions with analytics.

![Status: Experiment](https://img.shields.io/badge/Status-Experiment-yellow)

## What It Does

Manage recurring subscriptions with dashboard analytics, calendar view, and spending visualizations. Features auth, password reset, subscription tracking with Recharts graphs, and date management with date-fns. Built for keeping tabs on recurring payments.

## Tech Stack

`React` `Vite` `TypeScript` `Supabase` `Radix UI` `Tailwind CSS` `Recharts` `React Router` `date-fns` `React Day Picker`
